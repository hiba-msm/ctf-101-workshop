|---|---|---|

| [A Graduate Course in Applied Cryptography, Boneh & Shoup](https://toc.cryptobook.us/) · **Free** | Rigorous modern cryptography | Advanced |
| [Hacking: The Art of Exploitation, Jon Erickson (No Starch Press)](https://nostarch.com/hacking2.htm) | C, memory, networking and exploitation fundamentals | Intermediate |
| [Practical Binary Analysis, Dennis Andriesse (No Starch Press)](https://nostarch.com/practical-binary-analysis) | ELF format, disassembly and binary instrumentation | Advanced |
| [The Linux Command Line, William Shotts](https://linuxcommand.org/tlcl.php) · **Free** | Everything about the shell | Beginner |
| [Pro Git](https://git-scm.com/book/en/v2) · **Free** | Version control | Beginner |

## Ethics, law and responsible disclosure

Hacking skills come with responsibility. Know the rules before you practise.

| Resource | What |
|---|---|
| [UK Computer Misuse Act 1990](https://www.legislation.gov.uk/ukpga/1990/18/contents) | The UK law on unauthorised access |
| [US DOJ: Computer Fraud and Abuse Act guidance](https://www.justice.gov/jm/jm-9-48000-computer-fraud) | How US prosecutors apply the CFAA |
| [disclose.io](https://www.disclose.io/) | Standards and safe-harbour language for vulnerability disclosure programmes |
| [security.txt](https://securitytxt.org/) | How organisations publish where to report vulnerabilities (`/.well-known/security.txt`) |

Laws differ by country. If you're unsure whether something is legal, **don't do it** and ask a lecturer or your club first. The [Responsible use](../../README.md#ethics-and-responsible-use) section of the README summarises the rules for this workshop.
